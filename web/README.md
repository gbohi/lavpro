# Lavpro — Espace Pro (Angular 18)

Back-office web des centres de lavage : validation des lavages par QR code, statistiques,
paramétrage complet (services, véhicules, prix/points, récompenses, promotions, équipe, horaires…)
et administration de la plateforme.

```bash
npm install
npm start            # http://localhost:4200 (API attendue sur http://localhost:8000)
npm run build        # build de production dans dist/
```

L'URL de l'API se règle dans `src/environments/environment*.ts`.
